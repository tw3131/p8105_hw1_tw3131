``` r

as.numeric(pull(problem2_df, character_vector))
as.numeric(pull(problem2_df, factor_vector))
```

Converting the logical variable to numeric changes `TRUE` to 1 and
`FALSE` to 0, which explains why taking the mean of the logical variable
works.

Converting the character variable to numeric does not produce meaningful
numeric values because the character strings cannot be interpreted as
numbers.

Converting the factor variable to numeric returns the underlying integer
codes for the factor levels rather than meaningful quantitative values.
